ISSUE 1
-------
FILE: packages/web-ui/src/components/agents/ParallelAgentTerminalView.tsx
LINE: 153
CODE: return baseClasses.replace(/gap-\d+/, gapClass)
ISSUE: Gap replacement regex uses non-global flag
SEVERITY: MEDIUM
TYPE: Bug Risk - Fragile String Manipulation

DETAILS:
The regex /gap-\d+/ without 'g' flag only replaces first occurrence.
Current configs work because they have single 'gap-2', but this is fragile.
If configs are extended with multiple gap classes, replacement will fail silently.

IMPACT: Medium - Works now but fragile design pattern

RECOMMENDATION: Use /gap-\d+/g for global replacement, or redesign to exclude
hardcoded gaps from grid config strings.

ISSUE 2
-------
FILE: packages/web-ui/src/components/agents/ParallelAgentTerminalView.tsx
LINE: 174-175
CODE: `[data-testid="${testId}"] [data-panel-id="${panelId}"]`
ISSUE: DOM selector lacks input validation/escaping
SEVERITY: MEDIUM
TYPE: Security - CSS Selector Injection

DETAILS:
testId and panelId are interpolated into CSS selectors without escaping.
Special CSS characters (brackets, colons, hashes, dots, spaces) will break
or corrupt the selector causing focus to fail or focus wrong element.

EXAMPLES:
  testId = "parallel[1]" → [data-testid="parallel[1]"] (INVALID CSS)
  panelId = "panel:hover" → could match pseudo-class (WRONG BEHAVIOR)

IMPACT: Medium - Could cause focus to fail or select wrong element with side effects

RECOMMENDATION:
Option 1: Use CSS.escape(testId) and CSS.escape(panelId) before interpolation
Option 2: Use multiple simpler querySelector calls instead of complex selector
Option 3: Use Array.from(querySelectorAll(...)) with getAttribute matching

CODE: maxHeight: maxHeight === 'auto' ? undefined : maxHeight,
ISSUE: maxHeight prop accepts invalid CSS without validation
SEVERITY: LOW
TYPE: Input Validation - No Runtime Validation

DETAILS:
The maxHeight prop accepts any string but doesn't validate if it's valid CSS.
Invalid values like "invalid" or "1000%" will be applied to style object,
potentially causing layout breaks or browser warnings.

IMPACT: Low - Layout could be broken by invalid maxHeight, but primarily a
developer error rather than security issue.

RECOMMENDATION: Add validation regex to check for valid CSS length values
