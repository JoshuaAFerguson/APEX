3. RACE CONDITION IN CREDENTIAL SAVE
   File: packages/orchestrator/src/auth/credential-manager.ts:25-28
   Category: CONCURRENCY/FUNCTIONAL
   
   Issue:
   - Read-Modify-Write pattern without atomic operation
   - Method signature is async but uses sync writeFileSync
   - Concurrent calls can lose credential updates
   
   Code:
   ```typescript
   async saveCredentials(provider: string, creds: Credentials): Promise<void> {
     const allCreds = this.loadAll();      // Read
     allCreds[provider] = creds;            // Modify
     fs.writeFileSync(...);                 // ❌ Race condition
   }
   ```
   
   Impact: MEDIUM - Lost credentials in concurrent scenarios
   Fix: Use fs.promises.writeFile or add file locking
   Effort: 1-2 hours
