ISSUE 3/6: FRAGILE MOCK STATE MANAGEMENT
FILES: 
  - packages/web-ui/src/components/agents/__tests__/AgentTerminalPanel.acceptance.test.tsx:11-26
  - packages/web-ui/src/components/agents/__tests__/ParallelAgentGrid.integration.test.tsx:31-51
  - packages/web-ui/src/components/agents/__tests__/AgentTerminalPanel.keyboard-accessibility.test.tsx:15-30

SEVERITY: MEDIUM
STATUS: Code Quality Problem

Problem Description:
  Global mutable state variables (mockLogs, mockStreamState, etc.) are reset
  in beforeEach blocks, but resets are incomplete and inconsistent. This causes:
  - State leakage between tests
  - Flaky test execution (order-dependent)
  - Difficult debugging when state unexpectedly changes

Example Code:
  let mockLogs: AgentLogEntry[] = []
  let mockStreamState = { state: 'idle', ... }
  let mockAutoScroll = true
  let mockError: string | null = null
  
  beforeEach(() => {
    mockLogs = []
    mockStreamState = { ... }    // ❌ Incomplete reset
    mockAutoScroll = true        // ✓ Reset
    mockError = null             // ✓ Reset
    // ❌ MISSING: Reset mockNewItemsSinceScroll and others
  })

Failure Scenario:
  Test 1 sets: mockError = 'Connection timeout'
  Test 1 cleanup: NOT reset properly
  Test 2 expects: Fresh state without errors
  Test 2 fails: Because mockError from Test 1 still set

Recommended Fix:
  Implement factory function pattern:
  
  function createDefaultMockState() {
    return {
      mockLogs: [],
      mockStreamState: { /* all fields */ },
      mockAutoScroll: true,
      mockNewItemsSinceScroll: 0,
      mockError: null,
    }
  }
  
  beforeEach(() => {
    const defaults = createDefaultMockState()
    Object.assign(globalMockState, defaults)
  })
