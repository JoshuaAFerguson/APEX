# CODE REVIEW FINDINGS - AgentTerminalPanel & useAgentLogStream Tests

## CRITICAL ISSUES

### 1. packages/web-ui/src/hooks/useAgentLogStream.ts:244-252 - Global State Pollution - HIGH SEVERITY
Issue: Using global window.__agentLogSequenceCounter for sequence numbering creates race conditions
Impact: Multiple hook instances share the same counter; test interference in parallel execution
Fix: Use closure variable or instance-level counter instead of global window state

### 2. packages/web-ui/src/hooks/useAgentLogStream.ts:273-275 - Unsafe Global Initialization - MEDIUM SEVERITY
Issue: Module-level initialization of global counter at import time
Impact: Executes before test setup; cannot be reset between tests; test isolation issues
Fix: Move initialization into hook or use lazy initialization

### 3. packages/web-ui/src/hooks/__tests__/useAgentLogStream.test.tsx:156-198 - Incomplete Mock Setup - MEDIUM SEVERITY
Issue: Test uses vi.mocked() incorrectly inside test body instead of beforeEach
Code: const { useAgentLogStream } = vi.mocked(await import('@/hooks/useAgentLogStream'))
Impact: Dynamic import doesn't work with vitest mocks; setup should be at module level
Fix: Move mock setup to beforeEach or beforeAll hook

### 4. packages/web-ui/src/hooks/useAgentLogStream.ts:370-406 - Missing Error Handling - MEDIUM SEVERITY
Issue: updateConnectionStatus lacks try-catch for non-reconnector code paths
Impact: wsClient.isConnected() or getHealthState() failures could crash hook
Fix: Wrap all wsClient calls in try-catch blocks

### 5. packages/web-ui/src/hooks/__tests__/useAgentLogStream.test.tsx:933-975 - Fake Timers Cleanup - MEDIUM SEVERITY
Issue: Test uses vi.useFakeTimers() with cleanup in test body instead of afterEach
Impact: If test fails, fake timers not restored; affects subsequent tests
Fix: Move timer cleanup to afterEach hook
