FILE: packages/browser/src/permission-mocking/types.ts
LINE: 152
ISSUE: NavigatorWithMockedPermissions extends Navigator incompatibly
SEVERITY: HIGH
--------
Interface extends Navigator but overrides the query signature:
  Standard: (permissionDesc: PermissionDescriptor) => Promise<PermissionStatus>
  Custom:   (descriptor: PermissionDescriptor | MockPermissionDescriptor) => Promise<MockPermissionStatus>

The custom version accepts additional PermissionDescriptor types that the
standard DOM API doesn't recognize (e.g., 'storage-access').

This violates the Liskov Substitution Principle.

ACTION REQUIRED:
Option A (RECOMMENDED): Don't extend Navigator, use composition
  export interface NavigatorPermissionsMocked {
    permissions: {
      query(descriptor: PermissionDescriptor | MockPermissionDescriptor): Promise<MockPermissionStatus>;
      isMocked: true;
      _original?: Navigator['permissions'];
      _mockHandle?: MockPermissionHandle;
    };
  }

Option B: Use type assertion at usage sites instead of extending Navigator
  Use `navigator as NavigatorWithMockedPermissions` where needed

Option C: Restrict to standard permissions in interface and handle extras in implementation
