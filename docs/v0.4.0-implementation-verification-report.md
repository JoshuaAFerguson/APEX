**Location**: `packages/orchestrator/src/usage-manager.ts`

**Key Components Verified**:
- **UsageManager Class** - Complete implementation with time-based logic
- **Day/Night Mode Detection** - Configurable time windows with different resource thresholds
- **Usage Tracking** - Token, cost, and task tracking with daily statistics
- **Threshold Enforcement** - Different limits for day mode vs night mode
- **Mode Transition Handling** - Automatic switching and capacity restoration events

**Configuration Support**:
```typescript

  enabled: true,
  dayModeHours: [9, 10, 11, 12, 13, 14, 15, 16, 17],
  nightModeHours: [22, 23, 0, 1, 2, 3, 4, 5, 6],

    maxConcurrentTasks: 2,

    maxTokensPerTask: 1000000,
    maxCostPerTask: 20.0,
    maxConcurrentTasks: 5,
  },
}
```

**Location**: `packages/orchestrator/src/daemon-scheduler.ts`

**Key Components Verified**:
- **DaemonScheduler Class** - Manages scheduling decisions based on capacity
- **Capacity Monitoring** - Real-time threshold checking with different modes
- **Auto-Pause Logic** - Triggers when usage exceeds mode-specific thresholds
- **Auto-Resume Detection** - Capacity restoration events for budget reset, mode switch, and usage decrease

**Auto-Resume Triggers**:

3. **Usage Decrease**: Completed tasks reducing overall usage
