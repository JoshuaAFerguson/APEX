Issue #3: Callback Handler Memory Leak
  File: ApprovalGatePanel.tsx
  Severity: MEDIUM (FUNCTIONAL ISSUE)
  Lines: 127-132
  Problem: registerGateReceived/registerGateResolved called without cleanup
    - Handlers accumulate on every render
    - No tracking of registered handlers
    - Duplicate invocations
  Impact: Memory leak, performance degradation
  Fix: Return unsubscribe functions or use Set to track handlers
