7. packages/orchestrator/src/permission-store.ts - SCOPE VALIDATION MISSING
   Severity: MEDIUM
   Type: Security/Input Validation
   Lines: 348-350

   Code:
   private generatePermissionId(tool: string, scope?: string): string {
     const scopePart = scope ? `-${scope}` : '';
     const hash = Buffer.from(`${tool}${scopePart}`).toString('base64url');

   Issues:
   1. No validation of scope format before hashing
   2. Scope contains user input directly concatenated into hash
   3. base64url hashing provides no cryptographic security
   4. Special characters in scope could cause hash collisions

   Risk: Permission bypass if scope validation is inadequate

   Recommendations:
   1. Validate scope format (alphanumeric, limited special chars)
   2. Use cryptographic hash (SHA256) instead of base64url
   3. Document scope format requirements
   4. Add unit tests for scope edge cases

   Fix Example:
   ```typescript
   if (scope && !/^[a-zA-Z0-9._-]+$/.test(scope)) {
     throw new Error(`Invalid scope format: ${scope}`);
   }
   const hash = crypto.createHash('sha256')
     .update(`${tool}${scopePart}`)
     .digest('hex');
   ```
   Priority: MEDIUM
