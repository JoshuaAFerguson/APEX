### 5. packages/web-ui/src/components/changelog/ChangelogFilters.tsx:298 - Date Preset Detection Bug
**SEVERITY: MEDIUM**
**TYPE: Logic Error**

The `getCurrentDatePreset()` function uses `.toDateString()` comparison, which will always return 'custom' even when a preset matches because each preset.startDate() call creates a new Date object.

**Fix Required**:
```tsx
const getCurrentDatePreset = () => {
  if (!filters.startDate || !filters.endDate) return 'all'

  const filterStart = filters.startDate.getTime()
  const filterEnd = filters.endDate.getTime()

  for (const [key, preset] of Object.entries(FILTER_PRESETS)) {
    const presetStart = preset.startDate().getTime()
    const presetEnd = preset.endDate().getTime()

    if (filterStart === presetStart && filterEnd === presetEnd) {
      return key
    }
  }
  return 'custom'
}
```
